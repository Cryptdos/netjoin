# NetJoin v0.7 – Home page and breadcrumb navigation

Branch: `v0.7` (built on top of `v0.6`). Status: built, tested in demo mode, waiting for testing on the work PC.

## Why

With the Sites list hidden there was no way to move forward into a site, or back out of one, without opening the list again. v0.7 makes the breadcrumbs a complete way to get around, and adds a Home page at the top of the tree.

## Breadcrumbs

Explorer-style: `⌂ Home › Site › Area › Network`. Every `›` is a button; it turns to point down while its menu is open, and a second click closes it.

| Part | Click | Result |
|---|---|---|
| Any crumb name | click | Go to that Home / site / area |
| `›` between crumbs | click | Menu of everything at that level (siblings of the next crumb), current one highlighted |
| `›` at the end (blue) | click | Menu of what's inside the page you're on – step forward without the Sites list |
| Open menu | ↑ ↓ Enter, Esc | Keyboard navigation; Esc closes |

- The Sites list (☰) can stay closed – every page is reachable from Home through the crumbs.
- **Site / area header:** breadcrumbs, name and the counts line (networks · devices · BACnet · inactive · last scan) sit together on the left, buttons on the right, lined up with the counts line.
- **Contents strip** under a divider: one compact single-line button per area / network inside (name, subnet or network count, devices, inactive). They flow across the full width and wrap. Click one to go in.
- **Home** is the first row in the Sites list too.

## Home page

NetJoin now opens on Home. Buttons along the top: **Rejoin last**, **Discover networks…**, **Import site…**, **+ Add site**.

| Card | What it shows |
|---|---|
| Recent networks | Last 6 networks joined – path, address used, when, internet at the time – with a one-click **Join** |
| Needs attention | Networks with inactive devices – click opens the device list filtered to Missing. (Addresses-in-use and never-scanned notes were tried and dropped as noise.) |
| This PC | Adapter, address, MAC, internet, Npcap state, NetJoin version |
| Sites | A card per site: networks, devices, BACnet controllers, last joined, last scanned, inactive count |
| Stats | Sites, networks, devices found, BACnet controllers, joins this week, clashes dodged; devices by vendor (top 6 + Other); most visited site, busiest network, areas / subnets saved, joins all time, using NetJoin since |

"Clashes dodged" counts the times NetJoin found an address already in use and moved on to another one.

## Back end

- `GET /api/home` → `store.home_summary()` (recent, sites, attention, stats). One query pass over nodes, history, devices and scans; no new tables.
- `/api/status` now includes `version`.
- Version 0.7.0.

## Tested (demo mode)

- Home loads by default with all cards filled from seeded data (2 sites, 4 networks, joins, a clash, scans, one unplugged device).
- Sidebar hidden: Home ›▾ → site → ›▾ area → ›▾ network; `▾` sibling menus; Esc closes; Home crumb returns.
- Join from Home, and Needs attention → device list filtered to Missing.
- Window sizes 1920, 1366×650, 960, 390: no sideways overflow, no script errors.
- Fixed during testing: the current crumb shared the top bar's `current` class and stretched full-width on phones; Home cards now fill the first row instead of leaving a gap.
- 42 unit tests pass (new: `test_home_summary`).
