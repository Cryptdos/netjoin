# NetJoin v0.9.1 – device list improvements

Branch: `v0.9.1` (built on `main` / 0.9.0). Status: built, tested in demo mode.

## Network column (site and area pages)

Shows where each network is **from the page you're on**: on a site `Level 2 › FCUs`, on the Level 2 area just `FCUs`. Each one is a link to that network. Networks sharing a subnet show both, separated by `/`.

## Vendor filter: pick several

The vendor drop-down is a tick-list with a count per vendor, plus **Select all** / **Clear**. Nothing ticked = all vendors. Example: tick *Siemens* and *Siemens Building Technologies* to see every FCU whatever its MAC / BACnet vendor name. The button shows the vendor's name, or "3 vendors", and turns blue while a filter is on. Changing page clears it.

## Counts under the list

`Showing 5 of 11 devices · 2 missing · 6 on the imported list · 3 not checked yet` – each part only when it applies.

## Import CSV – a list of devices that should be there

**Import CSV** (next to Export CSV) loads a list of expected devices, e.g. from the last visit's export, the BMS schedule or a points list. Then a scan shows which are online and which are missing.

- **Columns** – found by their headings, any order, any case. Needs **IP** (`IP`, `IP address`, `Address`). Optional: **Name** (`Name`, `Device name`, `Object name`, `Description`, `Label`, `Tag`), **MAC**, **BACnet instance** (`Instance`, `Device instance`, `Device ID`), **Vendor** (`Manufacturer`), **Model** (`Type`, `Product`). A NetJoin Export CSV imports as-is.
- Comma, semicolon or tab separated; Excel's UTF-8 CSV is fine.
- **Where rows go** – each row goes to the network (under the page you imported on) whose subnet holds its IP. Import on a site to load a whole site's list in one go. Rows that fit no network, have a bad IP or are listed twice are skipped and reported.
- **Known devices** are flagged as on the list; blank details are filled in from the file, but anything a scan found is never overwritten.
- **Status of listed devices**

| Shown as | Meaning |
|---|---|
| On the list – not checked yet | No scan since the import |
| (normal row, LIST badge) | Found by the latest scan |
| Missing – on the list, never seen | Scanned since the import, never answered |
| Not seen since … | Was seen before, missed the latest scan |

- The **On list** chip shows only listed devices (selected straight after an import); listed rows have a small LIST badge.
- **Clear inactive** keeps the list. **Remove imported list** forgets it: never-seen rows go, the rest stay as ordinary devices.
- Export CSV gains an **On list** column, and a site's export / import (Settings) carries the list with it.

## Top bar

On a page with lots of buttons and a narrow window (e.g. a site at 1440 px), the bar now drops to two rows rather than cutting the page title down to a couple of letters.
