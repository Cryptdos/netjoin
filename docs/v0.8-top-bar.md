# NetJoin v0.8 – one top bar

Branch: `v0.8` (built on `v0.7`). Status: first build for feedback – layout expected to change after testing.

## Why

From v0.7 the page header (breadcrumbs, title, page buttons) was doing the job of a top bar, under the real top bar. Two stacked bars took about 135 px. v0.8 merges them into one bar of about 100 px, with every button in one place.

## Layout

```
[☰  NetJoin DEMO] │ Home › Site › Area › Network        [● Ethernet 2 ▾ │ 10.110.102.35/24 · Static · FCU 🌐 No internet] [Revert to DHCP] [⚙]
                  │ FCU                                  [🌐 Had internet at last join] [History ▾] [Edit] [Join]
```

| Part | What's there |
|---|---|
| Left | ☰ Sites list, logo, DEMO badge in demo mode |
| Middle | Breadcrumbs (row 1), page title (row 2) |
| Right, row 1 | **Connection chip**, Revert to DHCP, Settings |
| Right, row 2 | The page's own buttons (Home: Rejoin / Discover / Import / + Add site; site: Export / Edit / + Area / + Network; network: internet pill / History / Edit / Join) |

### Connection chip

`● Ethernet 2 ▾ │ ip/prefix · DHCP|Static · network 🌐 internet`

- The dot is the adapter's link: green = up, grey = down / none, amber = unplugged.
- The network name is a link to its page.
- Click the adapter name to open the connection panel: adapter picker, "Show virtual adapters too" (was the "all" tick box), device, MAC, address, internet, **Check internet**, **Rejoin last**. Esc or a click outside closes it.
- Revert to DHCP stays one click away beside the chip – it's the safety exit.

### Under the bar

- Network page: the four tiles (Network, Laptop address, Gateway / DNS, Next IP).
- Site / area page: the counts line and the Contents strip.
- Home: just the Home cards.

## Narrow windows

| Width | Bar |
|---|---|
| > 1280 px | As above |
| ≤ 1280 px | The chip drops its internet text (globe icon stays, with a tooltip) |
| ≤ 1100 px | Brand + chip on row 1, breadcrumbs row 2, title + page buttons row 3 |
| ≤ 700 px | Everything stacks; chip full width, DHCP and ⚙ on the row under it |

Toasts sit just under the bar whatever height it wraps to.

## Tested (demo mode, light and dark)

Home, site, area and network pages; connection panel open / Esc / outside click; Check internet; Revert to DHCP then Rejoin (lands on the network page); Join from the bar; widths 1536, 1366, 1100, 960 and 390 with no sideways scrolling; no script errors.
