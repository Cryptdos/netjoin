# NetJoin v0.8 – one top bar

Branch: `v0.8` (built on `v0.7`). Status: in progress, iterating on feedback.

## Why

From v0.7 the page header (breadcrumbs, title, page buttons) was doing the job of a top bar, under the real top bar. v0.8 merges them into **one line**, with the page's key facts in a slim strip attached underneath. Bar + strip is about 100 px on a 1366 px laptop, against roughly 200 px before.

## Layout

```
[☰ NetJoin DEMO] │ … › Level 2 › FCU      [🌐] [Edit] [Join] │ [● Ethernet 2 ▾ │ 10.110.102.35/24 · Static · FCU] [History ▾] [Revert to DHCP] [⚙]
NETWORK 10.110.102.0/24 255.255.255.0 │ GATEWAY / DNS – / – none set │ JOIN IP 10.110.102.35 first free
```

| Part | What's there |
|---|---|
| Brand | ☰ Sites list, logo, DEMO badge in demo mode |
| Breadcrumbs | `⌂ Home › Site › Area › Network` – the **last crumb is the page title** (large); no separate title line |
| Page buttons | Network: internet-at-last-join pill, Edit, Join. Site: Export, Edit, + Area, + Network. Home: Discover, Import, + Add site |
| Global | Connection chip, **History**, Revert to DHCP, Settings |
| Facts strip | Network: Network / Gateway & DNS / **Join IP** – the address Join tries first and how it was picked (first free, last used, static IP…); the allowed range is in its tooltip, written as `35 – 45` rather than `.35 – .45`. The separate Laptop address fact is gone – it's set in Edit and only needed there. Notes underneath if any. Site / area: counts line and Contents chips. Hidden on Home |

### Breadcrumbs that fit

The trail stays on one line. When it doesn't fit, levels fold from the top – Home first, then the site, and so on – into **…**. Click … for a menu of the hidden levels. The current page is never folded; if even that doesn't fit, its name is cut with an ellipsis (full name in the tab title).

### History (every page)

One list across all networks, newest first: network name, where it is (site › area), the address, worked / clashed, internet, time. Click one to join that network with that address and open its page. Entries for the page you're on are highlighted. Replaces the old per-network History and the **Rejoin** buttons (Home and the connection panel).

### Connection chip

`● Ethernet 2 ▾ │ ip/prefix · DHCP|Static · network 🌐 internet` – dot is the adapter link (green up, grey down, amber unplugged); network name links to its page. Click the adapter name for the panel: adapter picker, "Show virtual adapters too", device, MAC, address, internet, **Check internet**.

### Battery: no background polling

NetJoin no longer reads the adapter every 5 s (each read runs `netsh` twice) or the adapter list every 15 s. It reads them:
- after every action (Join, DHCP, History, Check internet…)
- when the window comes back into focus or becomes visible
- from the **↻** on This PC (Home)

The Activity log (in memory, cheap) is polled every 3 s only while the window is visible. Scans keep their own progress polling while running.

## Narrow windows – what gives way, in order

| Width | |
|---|---|
| ≤ 1680 px | Internet pill becomes an icon (text in tooltip) |
| ≤ 1440 px | "Revert to DHCP" → "DHCP" |
| ≤ 1366 px | Chip drops its internet text |
| ≤ 1280 px | Logo text hidden |
| ≤ 1100 px | Two rows: brand + breadcrumbs, then page buttons + global |
| ≤ 640 px | Everything stacks |

Breadcrumb folding works at every width.

## Back end

- `GET /api/history?limit=20` → `store.recent_history()`: one row per network + IP (latest outcome) across all networks, with `network`, `where`, `subnet`.

## Tested (demo mode, light and dark)

Home, site, area and network pages; long site / area / network names (folding and … menu); History list, highlight and join; connection panel open / Esc / outside click; Check internet; Revert to DHCP then ↻ on This PC; no `/status` requests in 11 s idle; widths 1536, 1366, 1280, 1150, 1100, 1024, 900, 640, 390 with no sideways scrolling; no script errors.
